# Ricochet Robots Solver

Static browser application for assembling Ricochet Robots boards and finding optimal solutions.

Built from the local Ricochet Robots Solver project. Search runs entirely in a browser Web Worker.

Based on https://github.com/johnnoel/ricochet-robots-solver (MIT). Tile data from https://github.com/CodingZeal/robots (MIT). See LICENSE.txt and LICENSE-tiles.txt.
